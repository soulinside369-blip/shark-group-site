# Shark Group — концепт-витрина

Одностраничный сайт-концепция для Shark Group (дерево, металл, камень; Сочи и Краснодарский край).
Статическая страница, ноль зависимостей.

- `index.html` — сайт (WebP-изображения в `m/`).
- `shark-group.html` — та же версия одним файлом (всё встроено), для пересылки.
- `Shark-Group-концепция-сайта.pdf` — презентация для клиента.

Разделы: трейлер, первый экран, направления, примерочная шпона, плитка и камень,
палитры материалов, процесс, «до/после», галерея, квиз. Фактуры дерева и плитки —
визуализации, к запуску заменяются макросъёмкой.

## Публикация
GitHub Pages: ветка `main`, корень. Форма на Pages работает в демо-режиме (без отправки).
