## 5. Бюджет и стратегия по месяцам (30 000 ₽/мес, 90 000 ₽ за 3 месяца)

| Кампания | Месяц 1 | Месяц 2 | Месяц 3 |
|---|---:|---:|---:|
| К1 Лестницы (поиск) | 10 000 | по итогам | по итогам |
| К2 Панели + фанера (поиск) | 7 000 | | |
| К3 Двери (поиск) | 5 000 | | |
| К4 Мебель / реставрация / мягкая (поиск) | 4 000 | | |
| К5 РСЯ + ретаргетинг | 4 000 | | |
| **Итого** | **30 000** | **30 000** | **30 000** |

- **Месяц 1 — сбор данных.** Стратегия «Максимум кликов» с недельным бюджетом (≈7 000 ₽/нед. на все кампании), ставки ограничены. Каждую неделю: чистка поисковых запросов → новые минус-слова. Цель — понять стоимость клика и заявки по каждому направлению.
- **Месяц 2 — перераспределение.** Деньги из кампаний без заявок → в кампании с самой дешёвой заявкой. Где набралось ≥ 10 заявок (цель `lead_sent`) — стратегия «Максимум конверсий» с оплатой за конверсию/целевой ценой заявки.
- **Месяц 3 — масштаб лучшего.** Оставляем 2–3 работающие кампании, тестируем новые объявления (A/B по 2 текста в группе), подключаем похожие аудитории.

**Как считать результат** (в админке есть источник заявки, в Метрике — цели):
стоимость заявки = расход кампании ÷ заявки; стоимость договора = расход ÷ договоры (статус «Договор» в админке).
Стоимость клика и прогноз показов — брать из «Прогноза бюджета» Директа при создании кампаний: свои
цифры CPC сюда не пишем, чтобы не выдумывать.
